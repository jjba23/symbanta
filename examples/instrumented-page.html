Custom events (#4)

Any event name is accepted, no schema migration needed. Declarative custom events send the name in data-symbanta-event and optional metadata in data-symbanta-props:

Or call the API directly from JavaScript:

window.symbanta.track("checkout-started", {cartSize: 3, currency: "EUR"});
